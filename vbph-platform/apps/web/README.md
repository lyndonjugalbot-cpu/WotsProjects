# @vbph/web

Next.js (App Router) web app for the Virtual Bridge PH platform — client, VA, and admin portals.

Run from the monorepo root, not this directory:

```bash
pnpm install
pnpm dev        # starts this app on http://localhost:3000
pnpm lint
pnpm typecheck
pnpm build
```

Requires `.env.local` in this directory — see `.env.local.example`.
