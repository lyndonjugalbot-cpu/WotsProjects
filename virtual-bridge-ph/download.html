First time opening it? You'll see a security warning — that's expected.

This is early-access software and isn't signed by Apple or Microsoft yet. On Mac: right-click (or Control-click) the app → Open → confirm in the dialog. On Windows: when SmartScreen appears, click More info → Run anyway. You'll only need to do this once per machine.
